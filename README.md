## 3. 고른 해결 방법
| 기능 | 고른 해결 | 구현 |
|---|---|---|
| 다른 사람의 변경 보기 | 어려운 해결 | `st.fragment`로 5초마다 갱신 |
| 필수 포함 역할을 지킬 수 없는 팀 | 어려운 해결 | 지원 단계에서 자리가 모자라게 되는 지원을 막음 |
| 같은 팀에 대기 중인 지원이 여럿 | 어려운 해결 | 승인 직전에 규칙을 다시 검사함 |
| 마지막 자리에 두 명이 동시에 들어감 | 어려운 해결 | `tf_members`의 유일성 제약 |
| AI 응답이 늦을 때 | 어려운 해결 | 모델마다 120초 전체 대기 시간을 재서 끊음 |
| 3차 모델까지 실패 | 어려운 해결 | 다섯 가지 검사를 통과하는 배정을 전수 탐색함 |
| AI 대기 중 화면 | 어려운 해결 | 몇 차 모델의 응답을 기다리는지 보여 줌 |
| DB 일시정지 막기 | 어려운 해결 | GitHub Actions 예약 작업으로 매일 DB에 질의함 |

## 로컬 실행
`.env.example`을 `.env`로 복사해 값을 넣고 실행한다.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

시험은 Supabase 없이 돌아간다.

```bash
pytest tests
```
